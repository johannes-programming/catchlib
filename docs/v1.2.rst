Introduction
------------

This project allows to catch exceptions easily.

Installation
------------

To install ``catchlib``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install catchlib

Typing
------

The typing conforms strictly to ``mypy``.

.. container:: versionadded

    **Added in version 1.1.**

.. container:: versionchanged

    **Changed in version 1.2:** The typing is now strict.

Features
--------

``catchlib.core``
"""""""""""""""""

``class catchlib.core.Catcher()``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This class allows to catch exceptions.
It can also be imported directly from ``catchlib``.

``catch(*args: type[BaseException]) -> contextlib.ContextDecorator``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This contextmanager catches exceptions of the given types.

``caught: BaseException | None = None``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This property stores the caught exception.

``release() -> None`` ``release(cause: BaseException | None) -> None``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

This method raises and deletes the ``caught`` exception.

``catchlib.tests``
""""""""""""""""""

``catchlib.tests.test() -> unittest.TextTestResult``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This project can be tested through its test function.

.. code-block:: python

    import catchlib.tests
